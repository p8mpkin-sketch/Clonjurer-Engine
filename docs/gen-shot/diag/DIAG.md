# 截图生成诊断(2026-11-15, 8897 @ 3e44acd)

样本: 8897 上 kind=screenshot 的生成任务只有 #577(输入为浏览器整窗截图 2844×2008, 附带文字「生成一颗爱心的网页」)。
并排图: `577_sheet.jpg`(原图 | 产出在 1440 / 768 / 390 视口)。

## 现在走哪条轨
- 截图输入不进代码直写轨(`settings.use_code_track` 只放行 description), 走 UIR 原型轨:
  确定性版面切分(tier=deterministic, 130 节点, 其中 19 个 image)→ 2~4 轮 llm「skeleton_fill」只改文字/样式 token。
- 大部分区块被当成**整块位图**从原图裁下贴回去(商品卡、导航甚至浏览器地址栏), 文字烤在图里;
  无法识别的区域退化成占位(签到卡变成一个巨大的「1x」)。
- 模型只用于读字(read_screenshot_text)和 skeleton_fill, 不写代码; 用户补充的文字提示在截图轨**完全不使用**。

## 评分口径
- `v3-segmented`: 产出在**原图像素宽度**(2844px)渲染后与原图比 structure / edge / text。#577: 结构 0.907, 边缘 0.889, 文字 0.188(召回 16%) → 75.8。
- 只在一个宽度上比, 平板/手机适配完全不进分; 位图拼贴能拿高结构分, 所以分数高估了实际效果。

## 具体缺陷
1. **视口取错**: 2844px 宽的 Retina 截图被当成 2844 CSS px 视口, 产出是定宽 2844px 页面, 在 1440 / 768 / 390 下全部横向溢出(scrollWidth=2844)。
2. **没裁浏览器外框**: 地址栏、扩展图标被当成页面内容复刻。
3. **文字是图片**: 文本召回 16%, 不可选中/不可编辑, 缩放发糊。
4. **无响应式**: 绝对定位 + 定宽, 平板/手机不可用。
5. **补充提示被忽略**, 且截图模式下界面上根本没有提示输入框(#577 的文字是文字描述页残留的)。
6. 局部识别失败(签到卡 → 「1x」)。

## 前端
- 截图模式只有文件选择框: 不支持 Ctrl/⌘+V 粘贴、拖放, 也没有补充提示输入。
- 提交卡顿: 本机实测 选图→预览 0.13s、提交请求 0.25s、切到任务列表 0.11s、生成运行期间 /api/v4/live 平均 23ms(最慢 0.35s), 未复现明显卡顿;
  可能来源是大图以 data URL 常驻 Vue 响应式状态、提交后串行等两次全量刷新才给反馈。改为: 前端压缩后上传、ObjectURL 预览、提交即反馈。
